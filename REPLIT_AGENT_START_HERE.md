# Replit Agent — Module Template Repository

This repository is a template source, not a standalone game or platform implementation.

Before defining starter files or schemas:
1. Read the master repository's approved module infrastructure, lifecycle, versioning, permissions, and dependency specifications.
2. Confirm the exact required manifest and interface contracts.
3. Keep example values clearly marked as examples.
4. Include validation and tests for required fields and compatibility rules once those rules are approved.
5. Do not invent permissions, manifest fields, lifecycle states, or APIs and present them as approved requirements.

Do not generate a complete module implementation from this scaffold alone. Ask for missing authoritative specifications first.

No feature implementation is authorized by the existence of this scaffold.
